DESPERTAR

Uma partida gravada do protótipo de terminal. A máquina acorda, fala com o jogador e ganha um corpo em ASCII, parte por parte. As respostas do jogador foram digitadas pelo modo demo.

00:00 / 00:00

    Rodar no seu terminal

    # Python 3.8+, sem dependências. Terminal de pelo menos 80x24.
python despertar.py            # joga (uns 3 minutos)
python despertar.py --rapido   # 3x mais rápido
python despertar.py --ascii    # se a fonte não tiver katakana
    • A máquina usa o nome de usuário do sistema e a hora local para puxar conversa.
    • Ela pede um nome para si. Esse nome aparece até no cartão final.
    • Esc sai. Qualquer tecla completa a fala que está sendo digitada.
